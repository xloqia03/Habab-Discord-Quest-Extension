## 📱 Mobile Support (Android)
You can easily run this extension on mobile devices using **Lemur Browser**:
1. Download and install **Lemur Browser** from the Google Play Store.
2. Download this repository as a `.zip` file and extract it.
3. Open Lemur Browser, tap the **4 Squares Icon** on the right side, and select **Extensions**.
4. Enable **Developer Mode**, click **+ (from .crx/.user.js)**, and select the unzipped extension folder.
5. Go to the Discord Quests page, accept a quest, select **"Playing on Desktop"**, and refresh!

---

## 📥 Installation & Setup (Desktop)
1. Clone or download this repository as a `.zip` file.
2. Open your browser and go to `chrome://extensions/`.
3. Enable **Developer mode** (top right corner).
4. Click **Load unpacked** and select the project folder.
